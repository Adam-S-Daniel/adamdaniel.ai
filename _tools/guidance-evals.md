Every AI coding agent working in my repositories reads one page of rules at
the start of each session, and nearly every rule on it was learned from a real
mistake. This page tests each section the same way the skills are tested — the
same task with and without the rule — and also asks whether a rule still
changes anything when all the others are present, since every section costs
words in every session.

The numbers update on their own as new runs land. The method is in
[How it works](https://github.com/Adam-S-Daniel/skills-evals/blob/main/docs/how-it-works.md).
